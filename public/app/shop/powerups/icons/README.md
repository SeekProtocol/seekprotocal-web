# Illustrated booster icons

Final 768px WebP artwork, generated from the map character references with individually art-directed poses. The ten icon files are shared byte-for-byte with seekar-app/assets/powerups/icons.

Use these illustrations for 2D views. The map GLBs and original stills are separate references and are unchanged. rare_boost maps to shiba; spawn_lure maps to whale; xp_boost maps to to_the_moon.

Full art direction and prompts: docs/boost-icon-design.md in seekprotocal-web. Manifest records source and final file hashes.
